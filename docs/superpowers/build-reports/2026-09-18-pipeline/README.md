# Build reports — 2026-09-18 pipeline plan

Copied verbatim from the git-ignored build workspace when the branch was handed over, so the
references in `README.md` and `docs/live-smoke-test.md` resolve on a fresh clone.

- `ledger.md` — the coordinator's running ledger: every task event, review outcome, ruling and
  deferred item, in order. The rulings alone are in `../../rulings/2026-09-18-pipeline-rulings.md`.
- `task-<n>-report.md`, `wave-<x>-report.md` — each implementer's own report: what was built,
  RED/GREEN evidence, brief corrections, concerns.

These are working records written for the coordinator, not polished documentation. Paths of the
PC the build ran on appear with the user name replaced by `<user>`. Nothing described in them ran
on Snowflake or Alteryx.
